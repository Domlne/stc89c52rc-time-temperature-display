# 8051 Basics

A beginner-friendly 8051 microcontroller code library for learning embedded hardware and software.

## Purpose

This repository contains 8051 examples written in C and Assembly.  
It covers GPIO, delays, buttons, timers, interrupts, UART, and basic hardware setup.

The code targets the classic 8051 architecture.  
SFR addresses and flashing tools may vary by vendor.
